# medRxiv preprint workflow

The journal manuscript may be posted as a preprint after the GitHub release and Zenodo software record are public.

## Before submission

1. Publish GitHub tag `v0.3.2`.
2. Publish the Zenodo record and confirm the DOI resolves.
3. Replace repository and DOI placeholders in the title page, manuscript, supplement, data workbook, and cover letter.
4. Create the final preprint PDF with author information and public repository citations.
5. Verify that the preprint and journal manuscript report identical numerical results.

## Suggested public links

Include the GitHub repository URL and versioned Zenodo DOI in the Data Availability and Code Availability statements. The medRxiv record can subsequently be added to `release_metadata.yml` and linked from the repository without changing the archived computational files.

## Disclosure

Disclose the preprint to the target journal during submission. Use the final medRxiv DOI or URL in the cover letter and journal submission system.
